Demo walkthrough
  1. Open a case and press Run case to start the LangGraph run.
  2. Read the documents, cited fields, flags and recommendation.
  3. Approve, conditionally approve, decline or request documents in the decision panel.
  4. The console mints the approval token, resumes the graph and shows the committed decision and audit chain.

The clean onboarding case recommends approve. The Northgate invoice recommends request documents. Cedar Pine is a hard stop: only decline or request documents are available.

Decision rules
  • Any hard stop → decline or request documents; never approve.
  • Two or more high flags → hold; missing documents always request documents.
  • One high flag or a medium flag → conditional approve.
  • The deterministic rule engine owns severity. The model may explain, not override.
